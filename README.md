# 에듀 패스파인더 (Edu Pathfinder) `v0.0.1`
> 지워나가며 발견하는 나만의 대학 진로 나침반 · 서울 주요 20개 대학 전공 소거 및 2028 대입 생기부 설계 대시보드

---

## 🌟 개요 및 기획 의도
**에듀 패스파인더(Edu Pathfinder)**는 중3 첫째 딸과 초6 둘째 아들 등 다자녀를 둔 학부모와 학생이 함께 대학 진로를 탐색할 수 있는 반응형 웹 애플리케이션입니다.

기존의 "하고 싶은 것을 억지로 찾아내는 방식" 대신, **"절대 안 맞는 것을 먼저 지워나가는 소거법(Elimination Method)"**을 통해 서울 주요 20개 대학의 수많은 전공 중 최적의 학과 3~5개를 압축해 냅니다.

최종 압축된 학과를 대상으로 **2022 개정 교육과정(고교학점제) 권장 선택과목**, **고1 공통과목 세특 탐구 아이디어**, 그리고 **중견기업 이상 / 대기업의 실제 추천 부서 및 직무**를 제공하여 고1 입학 시점부터 일관성 있는 학생부를 준비할 수 있도록 돕습니다.

## 🚀 주요 핵심 기능

### 1. 👨‍👩‍👧‍👦 다자녀 멀티 프로필 분기 관리 (Multi-Profile)
- 첫째(중3 딸)와 둘째(초6 아들) 등 자녀 이름을 등록하고 상단에서 원클릭으로 전환합니다.
- 자녀별로 소거한 학과, 관심 학과, 기피 태그, 생기부 메모가 브라우저 로컬 저장소(`LocalStorage`)에 완전히 격리되어 보관됩니다.

### 2. 🏛️ 서울 주요 20개 대학 전공 매핑
- **최상위/상위/중상위 20개교**: 서울대, 연세대, 고려대, 서강대, 성균관대, 한양대, 중앙대, 경희대, 한국외대, 서울시립대, 이화여대, 건국대, 동국대, 홍익대, 숙명여대, 국민대, 숭실대, 세종대, 서울과기대, 광운대
- 각 학과 카드마다 20개 대학 중 실제로 개설된 대학 리스트를 한눈에 확인할 수 있습니다.

### 3. 🎯 4단계 점진적 퍼널 (Progressive Disclosure)
1. **Step 1: 성향 진단 & 기피 조건 소거**
   - 문·이과 3문항 진단 및 문과/이과 계열 일괄 제외 기능
   - 8가지 기피 조건(수학 심화, 물리/역학, 피/실험, 코딩, 화학실험, 발표/토론, 외국어, 교직 기피) 원클릭 대량 소거
2. **Step 2: 20개 대학 학과 소거 보드**
   - 7대 계열 및 20개 대학 필터링
   - 카드 인터랙션: `[✕ 제외하기]`, `[△ 보류하기]`, `[★ 관심 담기]`
   - 실시간 잔여 학과 카운트 및 검색 기능
3. **Step 3: Top 3~5 후보 심층 분석 리포트 (5개 이하 압축 시 해금)**
   - 4년간 무엇을 배우는지(핵심 커리큘럼)
   - **중견기업 이상 및 대기업/공기업 타깃 리스트**
   - **입사 시 추천하는 구체적 실무 부서(Department) 및 직무 매핑**
4. **Step 4: 2022 개정 고교학점제 & 생기부 로드맵**
   - 핵심 권장 과목(필수) 및 일반 권장 과목(가산점) 체크리스트
   - **고1 공통국어, 공통수학, 공통영어, 통합사회, 통합과학 연계 세특 탐구 아이디어**
   - 부모-자녀 공동 생기부 메모장
   - [📄 진로 설계 리포트 인쇄 / PDF 저장] 기능

## 💻 로컬 실행 방법

Node.js 환경에서 아래 명령어를 실행하여 웹 브라우저로 열람할 수 있습니다.

```bash
# 1. 의존성 패키지 설치 (이미 완료됨)
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 브라우저 접속
# http://localhost:3030

# 4. 프로덕션 빌드 (이원화 지원)
# 4-1) Vercel 및 일반 웹 서비스 배포용 표준 빌드
npm run build

# 4-2) 오프라인 및 데모 전달용 단일 index.html 번들링
npm run build:single
# -> dist-single/index.html (CSS/JS 인라인 통합 단일 파일 생성)
```

## 🤖 듀얼 모드 AI 서비스 가이드 (Vercel & 로컬)

에듀 패스파인더는 **오프라인 단일 HTML 배포**와 **Vercel 실시간 AI 서비스**를 모두 지원하는 이원화 아키텍처로 설계되었습니다.

1. **단일 HTML 데모 배포 (`npm run build:single`)**
   - 별도 서버나 API Key 없이 독립형 단일 `index.html` 파일로 구동됩니다.
   - 4단계 심층 리포트는 신속하고 안정적인 **정적 룰베이스 템플릿 모드**로 안전하게 동작합니다.

2. **Vercel 온라인 실서비스 및 로컬 개발 (`npm run dev`)**
   - Vercel Serverless Function(`/api/`)을 통해 **Google Gemini LLM**과 안전하게 연동됩니다.
   - **주요 AI 기능**:
     - **[✨ AI 입시 컨설턴트 1:1 맞춤 정밀 진단]**: 학생의 1~3단계 진단 기록과 2028 대입 개편안을 결합한 맞춤형 심층 총평 자동 작성.
     - **[💬 AI 학과 멘토 1:1 Q&A]**: 학과 커리큘럼, 고교학점제 과목 선택, 취업 현실 등 학생의 자유 질문에 실시간 답변.
   - **환경 변수 설정**:
     - 로컬 테스트: 프로젝트 루트에 `.env.local` 생성 후 `GEMINI_API_KEY=your_key` 입력.
     - Vercel 배포: Vercel 대시보드 `Settings > Environment Variables`에 `GEMINI_API_KEY` 등록.

## 🛠️ 기술 스택
- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Backend / AI**: Vercel Serverless Functions (`/api`), Google Gemini API (`gemini-2.0-flash`)
- **Storage**: Browser LocalStorage (프로필별 네임스페이스 격리)
- **Design System**: 반응형(모바일, 태블릿, 데스크톱 PC 최적화), Pretendard 폰트, Print CSS 지원
